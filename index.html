Firebase Cloud Functions (대안 B) 연동 가이드

작동 원리 (대안 B)

1. 지식샘터 강의 URL이 등록되면, Cloud Function(스케줄러 10분 주기 또는 온디맨드)이 해당 강좌 페이지 HTML을 파싱합니다.

2. 지식샘터의 현재 수강 신청 인원(예: "현재 신청 7명 / 정원 10명")을 추출하여 Firestore `lectures/{lectureId}`의 `currentCount` 필드를 업데이트합니다.

3. Firestore의 `onSnapshot` 리스너를 통해 모든 교사의 캘린더 화면에 실시간으로 잔여석/신청현황이 즉각 갱신됩니다.

1. GitHub Actions 자동 크롤러 워크플로우 (.github/workflows/crawler.yml): 매 6시간 주기 자동 실행 
# .github/workflows/crawler.yml
name: Knowledge Fountain Enrolled Count Crawler
on:
  schedule:
    - cron: '0 */6 * * *'  # 6시간 주기
  workflow_dispatch:      # 수동 즉시 실행

jobs:
  crawl-and-update:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: pip install requests beautifulsoup4 firebase-admin
      - run: python crawler.py
        env:
          FIREBASE_SERVICE_ACCOUNT: ${{ secrets.FIREBASE_SERVICE_ACCOUNT }}
2. Python 크롤러 스크립트 (crawler.py): 
# crawler.py
import os, re, json, requests
from bs4 import BeautifulSoup
import firebase_admin
from firebase_admin import credentials, firestore

# Firebase Service Account 초기화 및 지식샘터 크롤링 수행
# Firestore lectures 문서의 enrolledCount, currentCount 필드 실시간 업데이트
GitHub Repository Secrets 등록 방법

1. Firebase 콘솔 > 프로젝트 설정 > 서비스 계정에서 새 비공개 키 생성(JSON 다운로드)

2. GitHub 저장소 > Settings > Secrets and variables > Actions > New repository secret 클릭

3. Name: FIREBASE_SERVICE_ACCOUNT / Value: 다운로드한 JSON 내용 전체 붙여넣기
